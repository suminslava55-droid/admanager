# Changelog

## [1.0.0] — 2026-11-07

Первый публичный релиз.

### Возможности
- Просмотр пользователей и групп Active Directory с фильтрами по OU и поиском.
- KPI-фильтры: привилегированные, неактивные, никогда не входившие, отключённые
  с группами, SPN, AS-REP, делегирование, SID History, пароли, пустые группы.
- Карточки пользователя и группы: доступы, риски, контакты, организация,
  участники, атрибуты.
- Определение привилегированных групп по настраиваемому списку и well-known SID.
- Прямые и эффективные группы (`tokenGroups`), включая основную группу.
- Управление УЗ: включение/отключение, разблокировка, сброс пароля,
  `pwdLastSet=0` и `pwdLastSet=-1`, срок действия, пароль без срока.
- Редактирование атрибутов, перемещение между OU, управление группами.
- Создание/удаление пользователей и групп.
- Копирование УЗ с переносом групп и атрибутов организации.
- Массовые операции по нескольким выбранным строкам.
- Экспорт CSV (UTF-8 BOM) и HTML-отчёт для ИБ.
- Журнал операций JSONL и диагностический отчёт.
- Настройка отображаемых проблем access review чекбоксами.
- Тёмная тема WPF, кастомные диалоги, тёмный заголовок окна.
- Self-contained сборка для Windows x64.

### Исправления
- Корректный разбор COM-значений AD (`pwdLastSet`, `accountExpires`, `lastLogon`,
  `lockoutTime`), из-за которых ранее неверно определялся статус пароля.
- Исправлено отображение количества участников группы после открытия карточки
  (обычный LDAP `member` и постраничное чтение `member;range=...`).
- Убраны ложные «Пароль истёк» для УЗ с флагом «пароль не истекает».
- Убраны лишние уведомления «Нет почты», «Нет отдела», «Нет руководителя».
- Убрано дублирование кнопки сброса пароля во вкладке «Доступ».
- Исправлена работа раскрытия/закрытия узлов дерева с первого клика.
- Добавлен запрос повышения прав администратора при запуске (UAC).
- Удалён S4U-вход через `GetAuthorizationGroups`, создававший события 4648;
  эффективные группы читаются через `tokenGroups`.
- Группы загружаются по всему домену, а не только по выбранному OU.
- Улучшено распознавание привилегированных локализованных групп.
